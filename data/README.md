# Data Description

This folder is reserved for data used in the PM₂.₅ and meteorological analysis.

## Required Variables

The DLNM analysis requires the following variables:

- Date
- Temperature
- Relative Humidity
- Wind Speed
- Atmospheric Pressure
- Daily Mean PM₂.₅ Concentration

## Data Organization

The current R workflow is designed to read an Excel workbook containing multiple worksheets, where each worksheet represents a monitoring station or study location.

## Data Availability

The original research dataset is not included in this repository. Users can adapt the R script to their own PM₂.₅ and meteorological datasets using the variable structure described above.
